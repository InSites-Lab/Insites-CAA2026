# Q&A Note: Claim Extraction and Validation

**Anticipated question**: How did you extract the claims, claim by claim? What definition did you use, with what tool, and how did you check validity?

---

## Spoken answer / slide note

We analyzed the full session transcript using directed qualitative content analysis. The unit of analysis is the individual substantive claim, defined as any statement that attributes significance, interprets evidence, identifies a value, draws a connection, or makes an analytical judgment about the site. Procedural text and direct quotations without interpretation were excluded.

Extraction was done with an agentic extraction protocol, an LLM-based coding script run three independent times over the transcript, with results reviewed and consolidated by the second author. This yielded 45 claims, each linked to its source passage.

Validity rests on two mechanisms. First, traceability: every claim is page-referenced to the source documents, so each classification can be independently checked. Second, expert judgment: the heritage expert reviewed every claim in session, accepting, correcting, or rejecting it. We make no reliability claim beyond this single case; the protocol and full claim-level dataset are in the public repository.

---

## Key points if pressed further

- **Definition of a claim**: attributes significance, interprets evidence, identifies a value, draws a connection, or makes an analytical judgment. Excluded: stage briefs, prompts, formatting, uninterpreted quotation.
- **Tool**: agentic extraction protocol (LLM-based coding), three independent runs, human-reviewed consolidation.
- **Classification**: each claim coded by epistemic level as assigned by the system: unmarked (explicit in sources), ° (synthesis), 💭 (hypothesis).
- **Validity**: page-referenced traceability plus in-session expert review of every claim. Single case, single expert, single coder: descriptive observations, not inferential reliability.
