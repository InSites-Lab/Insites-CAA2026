# Research Insights & Methods

Cross-paper research findings and reusable methods from the InSites Knowledge Lab.

Unlike `Heritage4.0/` (one paper) or `design/specs/` (how a bot feature works), this folder holds **durable lab insights** that can feed multiple papers and ongoing development — methods we validated in practice and want to keep.

| File | What it is |
|------|-----------|
| `genius-loci-experiential-method.md` | Validated method: analyzing people's lived impressions of a place into an *experiential knowledge layer* that feeds a CBSA significance assessment. First applied at the Madatech (Baerwald). |

**Conventions:** one file per method/insight; lead with status + provenance; English; cross-link the operational spec (`../design/specs/`) and any paper that uses it (`../Heritage4.0/`).
